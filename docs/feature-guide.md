# Zebra Ops AI 助手 · 功能说明文档

> 面向产品与使用：完整说明 Web 工作台上每个按钮、选项、交互所对应的功能，以及它们调用的后端能力与预期行为。

---

## 1. 产品定位

Zebra Ops AI 助手是一个**智能运维助手**，围绕「对话 + 知识库 + 告警分析」提供三大能力：

| 能力 | 说明 |
|---|---|
| 智能对话 | RAG 知识库增强 + ReAct Agent 工具调用，支持快速（一次性返回）与流式（SSE 逐字）两种模式 |
| 知识库管理 | 上传 Markdown / TXT 文档，自动切分、向量化、入库；同源文件重复上传会覆盖更新 |
| AI 告警分析 | 一键拉取活跃告警 → 检索处理手册 → 查询关联日志 → 生成结构化运维报告 |

## 2. 界面功能总览（按区域）

### 2.1 左侧边栏（会话历史）

| 界面元素 | 功能 | 触发行为 |
|---|---|---|
| **新建**（+）按钮 | 新建会话 | 保存当前对话 → 清空聊天区 → 生成新会话 ID → 重置为「快速」模式 |
| **历史会话列表** | 切换会话 | 点击任意历史项加载该会话的消息；切换前自动保存当前未保存对话 |
| **历史项标题** | 会话标题 | 取首条用户消息前 30 字，超长截断加 `...` |
| **历史项副标题** | 元信息 | 显示消息条数 + 最近更新时间（月/日 时:分） |
| **删除（垃圾桶）** | 删除会话 | 悬停历史项时显示；点击删除该会话（本地存储）；若删除的是当前会话则新建空会话 |

> 会话历史保存在浏览器 `localStorage`（key: `chatHistories`），上限 **50 条**，超出自动丢弃最旧的。

### 2.2 顶部栏（Header）

| 界面元素 | 功能 | 触发行为 |
|---|---|---|
| **菜单图标**（移动端） | 打开/收起侧栏 | ≤768px 显示；点击抽屉式展开侧栏 + 遮罩 |
| **品牌区** | 产品标识 | Zebra Ops AI 助手 Logo + 名称 |
| **状态指示点 + 文案** | 运行状态 | `就绪`（绿） / `思考中`（橙，动画） / `分析中`（橙） / `错误`（红） |
| **上传文档** 按钮 | 上传文件入口 | 点击弹出系统文件选择框（限 `.txt/.md/.markdown`，≤50MB） |
| **AI Ops** 按钮 | 一键告警分析 | 强制新建会话 → 显示「分析中」遮罩 → 调用 `/api/ai_ops` → 渲染报告 + 可折叠步骤 |
| **亮色/暗色** 按钮 | 主题切换 | 切换亮/暗主题（`localStorage: zebra_theme` 记忆），同步代码高亮主题 |

### 2.4 输入区（Composer）

| 界面元素 | 功能 | 触发行为 |
|---|---|---|
| **文本输入框** | 输入问题 | 占位「输入你的问题…（Enter 发送）」；Enter 发送；字数上限 1000 |
| **更多选项（⋯）** | 打开工具菜单 | 弹出小菜单，含「上传文档」入口（次要入口） |
| **模式选择（快速/流式）** | 对话模式 | 下拉菜单：**快速**（新，请求-响应） / **流式**（SSE 逐字输出） |
| **发送按钮**（圆形） | 发送消息 | 发送后锁定输入（思考中），完成后恢复 |
| **加载遮罩** | 长任务提示 | AI Ops / 上传时全屏遮罩：「AI 运维分析中，请稍候…」 |

### 2.5 消息交互细节

- **流式光标**：助手回复生成中显示 `▍` 闪烁光标，完成后移除。
- **自动滚动**：接近底部时新内容自动跟随滚动；发送后强制跳到底部。
- **防 XSS**：Markdown 经 `marked` 解析后由 `DOMPurify` 白名单清洗；消息文本使用 `textContent` 写入。

## 3. 核心功能流程

### 3.1 快速对话（快速模式）
```
输入问题 → POST /api/chat {Id, Question}
   → 后端 RAG 检索 + ReAct Agent 工具调用
   → 一次性返回完整答案 → Markdown 渲染展示
```

### 3.2 流式对话（流式模式）
```
输入问题 → POST /api/chat_stream（SSE）
   → 逐 token 推送（data 行）→ 前端增量渲染 + 闪烁光标
   → 收到 done/[DONE] → 结束，Markdown 化并保存历史
```

### 3.3 AI 告警分析（AI Ops）
```
点击 AI Ops
  → 强制 newChat()（新建会话、清空当前对话）
  → 显示「分析中」遮罩
  → POST /api/ai_ops {Id}
  → 后端 Plan-Execute-RePlan Agent：
      ① query_prometheus_alerts 拉活跃告警
      ② 按告警名 query_internal_docs 查处理方案（仅限文档内信息）
      ③ get_current_time / 日志工具（地域+日志主题）补全上下文
      ④ 汇总生成《告警分析报告》
  → 报告写入后端会话记忆（同一会话内可追问引用）
  → 前端渲染报告 + 「查看详细步骤 (N条)」折叠明细
```
> 每次点击的**前端流程一致**；后端结果取决于**当前时刻活跃告警**与 LLM 输出，非固定。

### 3.4 文档上传建库
```
选择文件（.txt/.md/.markdown，≤50MB）
  → POST /api/upload（multipart/form-data）
  → 后端保存文件 → Markdown 按 # 标题切分 → 向量化（embedding）
  → 写入 Milvus（同源文件 _source 先删旧再重建 = 覆盖更新）
  → 返回 fileName/path/size → 页面提示「上传到知识库成功」
```

## 4. 与聊天输入的区别（AI Ops vs 普通对话）

| 维度 | 点击 AI Ops 按钮 | 聊天窗口输入 |
|---|---|---|
| 请求接口 | `/api/ai_ops` | `/api/chat` 或 `/api/chat_stream` |
| 底层编排 | Plan-Execute-RePlan（Think 规划 + Quick 执行，外层 MaxIter=10） | ReAct Agent + RAG（MaxStep=25） |
| 输入内容 | 固定内置指令（不可自定义） | 用户自由输入 |
| 输出形态 | 非流式报告 + 可折叠步骤 | 快速整段 / 流式逐字 |
| 会话行为 | 强制新建会话并清空 | 在当前会话继续 |
| 工具集 | 告警/文档/时间/日志 | 时间/文档/MCP日志/告警 + RAG 检索 |

## 5. 数据与状态说明

| 项 | 位置 | 说明 |
|---|---|---|
| 会话历史 | 浏览器 `localStorage` | key `chatHistories`，上限 50 条 |
| 主题偏好 | 浏览器 `localStorage` | key `zebra_theme`（`dark`/`light`） |
| 后端会话记忆 | Go 内存 `internal/memory` | 滑动窗口 6 条 + 24h TTL + 1 万条上限 |
| 知识库向量 | Milvus | FloatVector 2048 + L2 度量 |
| 上传文件 | 服务器 `storage/uploads` | 配置 `file_dir` 可改 |
| 密钥 | 本地 `config.yaml`（`gitignore`） | 不入库；CLS 日志 MCP 服务经 `.env` 环境变量配置 |

## 6. 常见问题

- **为什么点 AI Ops 会清掉当前对话？** 设计如此——AI Ops 固定走「新会话 + 专用分析管线」，保证报告上下文干净。
- **赞/踩有什么实际作用？** 当前为**本地视觉反馈**（前端标记），未接入后端反馈接口（后端暂无 `/feedback` 接口）。
- **上传后立刻能查到吗？** 上传完成即向量化入库，可在当前对话中通过 RAG 检索使用。
- **流式模式卡住怎么办？** 可点击停止前无停止按钮，等待超时或刷新；重新发送即可。
